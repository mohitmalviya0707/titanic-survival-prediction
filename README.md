# Titanic Survival Prediction (Kaggle)

This repository contains an end-to-end machine learning pipeline for the Kaggle
Titanic – Machine Learning from Disaster competition.

## Workflow
- Data cleaning & preprocessing
- Feature engineering (Title, FamilySize, IsAlone)
- Categorical encoding
- Random Forest model training
- Prediction & Kaggle submission

## Model
- RandomForestClassifier
- Tuned hyperparameters
- Kaggle score: ~0.77 (first submission)
